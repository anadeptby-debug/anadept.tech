# Anadept — сайт

Сайт компании Anadept (автоматизация и ИИ для производства и бизнеса). Astro 5, два языка (RU без префикса, EN под `/en/`),
все страницы собираются из `src/pages/[...slug].astro`, тексты в `src/i18n/*.ts`. Хостинг — Cloudflare Worker
(`wrangler.jsonc`, код в `worker/src`), он же отвечает на `/api/audit`, `/api/chat`, `/api/contact`.

## Запуск

- `npm run dev` — сайт на http://localhost:4321 с горячей перезагрузкой (API не работает).
- `npm run cf:dev` — сборка + воркер на http://localhost:8787: сайт и API вместе, ИИ и Telegram — заглушки.
- `npm run build` — проверка сборки перед коммитом.

## Дизайн-система (не менять без запроса)

- Бренд: графит `--dark #121722`, белые панели, персиковый `--peach #ff9b7d` (кнопки), оранжевый `--accent #e8603a`
  (крупные цифры), `--accent-text #bf4520` (мелкий акцентный текст, 4.5:1). Шрифты: Onest (заголовки), Wix Madefor Display (текст).
- Все цвета, тени и шрифты — только через токены в `:root` в `src/styles/global.css`. Никаких литералов в компонентах.
- Анимируем только `transform` и `opacity`; у каждой анимации есть вариант для `prefers-reduced-motion`.
- Скрытые до появления блоки (`.reveal`, шаги WorkSteps) прячутся только под классом `.js` (ставится в `<head>`).
- Фокус: `:focus-visible` с `--focus-ring` (тёмный на светлом, персиковый на тёмных блоках — список блоков в global.css).
- Без надписей капсом над заголовками, без капса с разрядкой в подписях, без стрелок «→» после текста ссылок,
  без перечислений через «·». Цифры и факты — только реальные, ничего не выдумываем.

## Скилл Hallmark

Лежит в `.claude/skills/hallmark` (https://github.com/nutlope/hallmark, MIT). Вызывается явно: `/hallmark audit src`,
`/hallmark redesign src`. Рабочая папка — `.hallmark/` (скриншоты и отчёты не коммитятся, `log.json` коммитится).
Линтер: `node .claude/skills/hallmark/scripts/sloplint.mjs src --genre modern-minimal --render --url http://localhost:4321/`
(для `--render` нужен `puppeteer-core`, например `npm i -g puppeteer-core`, и Chrome; путь к нему — в `CHROME_PATH`).

Известные ложные срабатывания: 34 на `Base.astro` (стили подключены импортом во frontmatter), 73 на обрезанном
многоточием и свёрнутом тексте (карточки услуг, «Коротко о результатах»).
