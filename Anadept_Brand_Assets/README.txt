ANADEPT — Комплект бренд-ассетов

01_Icon — отдельно фирменный знак, PNG на белом и чёрном фоне + прозрачные PNG.
02_Wordmark — отдельно надпись Anadept, PNG на белом и чёрном фоне + прозрачные PNG.
03_Favicons_ICO — favicon_light.ico и favicon_dark.ico (16, 24, 32, 48, 64, 128, 256 px внутри каждого ICO); PNG для сайтов и приложений.
04_Full_Logo — горизонтальный логотип (знак + надпись), светлая и тёмная версии, включая прозрачные PNG.
05_Originals — исходные PNG изображений, из которых подготовлен комплект.

Вариант light предназначен для светлого фона: тёмный знак/текст и персиково-оранжевый акцент.
Вариант dark предназначен для тёмного фона: белый знак/текст и тот же оранжевый акцент.

PNG — без потерь; ICO содержит несколько размеров для браузеров.
ВАЖНО: исходные изображения растровые, а не исходные векторные файлы.
Для печати очень большого формата или бесконечного масштабирования нужен отдельный векторный мастер (SVG/PDF), построенный вручную по утверждённому знаку.
